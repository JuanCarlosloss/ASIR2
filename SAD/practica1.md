# Principales extensiones Visual Studio Code
## 1. PHP
- PHP Intelephense: Ofrece autocompletado, navegación por el código, diagnóstico de errores y soporte para múltiples estándares de PHP.
- ¿Por qué?: Es una de las extensiones más completas para el desarrollo en PHP. Ofrece autocompletado inteligente, validación de errores en tiempo real, navegación por el código (ir a definiciones, referencias, etc.) y hasta sugerencias de optimización. Esto agiliza enormemente el trabajo con grandes proyectos en PHP.
- PHP Debug: Permite depurar código PHP utilizando Xdebug directamente en VSCode.
- PHP Namespace Resolver: Ayuda a generar, limpiar y organizar los namespaces de PHP automáticamente.
- PHP DocBlocker: Automatiza la generación de comentarios DocBlock en PHP, muy útil para documentar funciones y clases.
## 2. HTML
- HTML Snippets: Ofrece fragmentos de código (snippets) para HTML, incluyendo estructuras comunes como formularios, tablas, divs, etc.
- Live Server: Lanza un servidor local con auto-recarga para ver los cambios en tiempo real mientras editas tu HTML, CSS y JS.
- ¿Por qué?: Esta extensión es extremadamente útil porque te permite lanzar un servidor local con recarga automática, lo que significa que puedes ver los cambios en tiempo real a medida que editas tu código HTML (también CSS y JS). Ahorra mucho tiempo al evitar tener que refrescar manualmente el navegador para cada cambio.
- Auto Close Tag: Cierra automáticamente las etiquetas HTML abiertas cuando tecleas el símbolo </.
- Auto Rename Tag: Renombra automáticamente las etiquetas de cierre cuando cambias la de apertura en HTML y XML.
# 3. CSS
- CSS Peek: Permite "espiar" (peek) y saltar a las definiciones de las clases y los IDs CSS directamente desde tu HTML.
- IntelliSense for CSS class names in HTML: Proporciona autocompletado de nombres de clases de CSS dentro del código HTML.
- ¿Por qué?: A veces puede ser difícil recordar todas las clases que has definido en tu CSS. Esta extensión proporciona autocompletado de las clases de CSS directamente en tu código HTML, lo que te ayuda a ahorrar tiempo y reduce errores tipográficos, ya que evita que escribas mal las clases.
- PostCSS Language Support: Añade soporte para PostCSS, que es un compilador CSS con plugins avanzados.
- Stylelint: Valida tu código CSS y SCSS utilizando el popular linter stylelint para asegurar que sigues las mejores prácticas y estándares.
# 4. JavaScript
- ESLint: Es un linter para JavaScript que ayuda a identificar y corregir errores, además de aplicar reglas de estilo en tu código JS.
- ¿Por qué?: ESLint es el estándar de facto para mantener un código limpio y libre de errores en JavaScript. Te ayuda a identificar problemas de sintaxis, errores potenciales y también te fuerza a seguir reglas de estilo y mejores prácticas, lo que es crucial en proyectos colaborativos y a largo plazo.
- JavaScript (ES6) code snippets: Ofrece fragmentos de código útiles para JavaScript ES6, con atajos rápidos para funciones, objetos, importaciones, etc.
- Prettier - Code formatter: Un formateador de código que soporta varios lenguajes, incluido JavaScript, ayudando a mantener un código uniforme y limpio.
- Path Intellisense: Proporciona autocompletado de rutas de archivos en tu proyecto, lo que es útil para importar módulos o incluir archivos.
