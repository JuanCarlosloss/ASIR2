## 1. Pydictor
- Extensión compatible con python 3
- Para instalar pydictor en el equipo necesitaremos buscar el repositorio en github
- El repositorio es: https://github.com/landgrey/pydictor
- Luego descargar el contenido del repositorio usaremos el comando git clone
- Iremos a una ubicación donde queremos descargar el repositorio
- Usaremos el siguiente comando **"git clone https://github.com/landgrey/pydictor"**
![Pydictor1](https://github.com/user-attachments/assets/2514175f-f437-46d4-859e-cea065bff6fa)
